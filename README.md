# Blotter — live desk

The public website for Blotter: a paper-trading desk where bots are born hourly, trade real Binance prices with fake money, and are culled every midnight (Tashkent time).

- Website: served from `docs/` with GitHub Pages
- `desk-data` branch: the desk's report, refreshed every 10 minutes by the server (this is what the site reads)
- `lab/strategies/duel-*.js`: the five Standoff bots, shown on the Standoff page

Paper trading only. No real money. Not financial advice. The engine that runs the desk is not part of this repository.
